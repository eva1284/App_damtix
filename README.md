# contents controller

Damtix의 SNS 콘텐츠(인스타그램 3개 계정 + 자사몰)를 브랜드 기준에 맞게 만들고 검수하는 **내 Mac용 프로그램**이에요.
Claude 데스크톱 앱과 연결해서, Claude가 항상 같은 브랜드·제품 기준으로 작업하게 해요.

지금은 **2단계**까지 만들었어요.

- 1단계: 브랜드 기준 관리, 문구 검사, Claude 연결
- 2단계: 캘린더, 작업 기획, 캡션을 Claude에게 맡기고 한국어 역번역으로 검수
- 3단계: 레퍼런스 보관함, 이미지 제작(구도 시안 → 생성 → 핀 메모 검수 → 최종 컨펌), 최적화·Mac 폴더·Google Drive 저장
- 4단계: 영상 제작(스토리보드 → Claude 편집 또는 CapCut 직접 편집 → 타임라인 메모 검수 → 나라별 자막 → 최종 컨펌), 최종 컨펌 때 이미지 업스케일 선택

HTML(자사몰) 제작은 다음 단계에서 열려요.

## 처음 설치 (한 번만)

1. **Node.js 설치**: https://nodejs.org/ko/download 에서 LTS 버전을 내려받아 설치해요.
2. **프로그램 내려받기**: GitHub에서 이 저장소를 내려받아요. (GitHub Desktop 앱으로 Clone 하면 나중에 업데이트가 쉬워요.)
3. **실행**: 폴더 안의 `start.command`를 더블클릭해요.
   - 처음에 "확인되지 않은 개발자" 경고가 나오면: 파일을 **오른쪽 클릭 → 열기 → 열기**.
   - 처음 실행 때 필요한 파일을 1분 정도 내려받아요.
   - 브라우저에 http://localhost:4321 이 열리면 성공이에요.
4. **자동 실행 켜기 (추천)**: `autostart.command`를 한 번 더블클릭해요. 이제 Mac에 로그인하면 프로그램이 뒤에서 알아서 켜져요. 터미널 창을 켜 둘 필요가 없고, Claude 앱을 껐다 켜도 꺼지지 않아요.
   - "node가 데스크탑 폴더에 접근하려고 합니다" 창이 뜨면 [허용]을 눌러요.
   - 끄고 싶으면 터미널에서 `node scripts/autostart.js uninstall`.
5. **Claude 연결**: `connect-claude.command`를 더블클릭한 뒤, Claude 앱을 **완전히 종료(⌘Q)했다가 다시 열어요**.
   Claude에게 "contents controller 브랜드 기준 보여줘"라고 말해 보세요.

## 매일 쓰는 법

- 자동 실행을 켰다면 브라우저에서 http://localhost:4321 만 열면 돼요.
- 자동 실행을 켜지 않았다면 `start.command`를 더블클릭해요. 이때는 터미널 창을 닫으면 프로그램이 꺼져요.
- "사이트에 연결할 수 없음"이 나오면 프로그램이 꺼진 거예요. `start.command`를 더블클릭하거나 `autostart.command`로 자동 실행을 켜 주세요.
- **폰에서 열기**: Mac과 같은 Wi-Fi에서, 홈 화면에 나오는 주소를 폰 브라우저로 열고 6자리 접속 코드를 넣어요.
- Mac이 꺼져 있거나 잠자기 상태면 폰에서도 열리지 않아요.

## 캘린더와 캡션 (2단계)

1. **캘린더**에서 칸의 **+** (또는 **+ 새 작업**)를 눌러 작업을 만들어요. 종류(이미지·영상·HTML), 계정, 게시일, 제품, 한국어 기획 메모를 넣어요.
   - 그 시장에서 팔지 않는 제품은 만들 수 없어요 (예: 19% 다크스팟 세럼은 미국 전용).
   - "캡션 작성도 바로 Claude에게 맡기기"를 체크하면 바로 Claude 할 일에 올라가요.
2. Claude 데스크톱 앱에 **"contents controller 대기 작업 처리해줘"**라고 입력해요. 여러 건을 모아 두었다가 한 번에 맡겨도 돼요.
3. Claude가 그 계정 언어로 캡션·해시태그·멘션을 쓰고, **한국어 역번역**을 붙여서 보내요. 브랜드 기준에 어긋나면 저장되지 않아서 Claude가 고쳐서 다시 보내요.
4. 홈의 **내 차례**에서 열어, 원문과 역번역을 비교해 검수해요.
   - 고칠 점이 있으면 **수정 요청**에 한국어로 적어요. Claude 앱에 다시 "처리해줘"라고 하면 고쳐서 보내요.
   - 괜찮으면 **캡션 컨펌**. 그다음 **캡션·해시태그 복사**로 인스타그램에 붙여넣어요.

Claude 앱에서 "다음 주 일본 계정 게시물 3개 기획해줘"라고 하면 Claude가 캘린더에 작업을 만들어 둘 수도 있어요.

## 레퍼런스 (3단계)

- **레퍼런스** 화면이나 작업 화면에 이미지·영상을 끌어다 놓거나, 캡처한 뒤 **⌘V**로 붙여넣거나, 주소를 넣어요.
- 작업 화면에서 넣으면 그 작업에 바로 연결돼요. 보관함에 모아 둔 것은 **보관함에서 고르기**로 붙여요.
- **가져올 점**(예: 색감만, 구도만)을 적어 두면 Claude가 그 부분만 참고해요.
- Claude가 이미지를 직접 보고 구도·빛·색감을 한국어로 분석해 둬요. 인스타그램·틱톡 영상 주소는 Claude가 못 볼 때가 많으니 화면 녹화나 캡처를 같이 넣어 주세요.

## 이미지 제작 (3단계)

1. 이미지 작업 화면에서 **구도 시안 맡기기** → Claude가 크레딧 없이 컴퓨터로 그린 구도 시안 2~3개를 보내요.
2. 시안을 고르고 메모를 남겨 **이 시안으로 이미지 만들기 맡기기**. 마음에 안 들면 시안 수정 요청.
3. Claude가 제품 기준 이미지(이미지정리의 제품 폴더)와 모델 폴더 사진을 참조해서 Higgsfield로 만들어요. **만들기 전에 예상 크레딧을 먼저 알려줘요.**
4. 결과 이미지를 누르면 핀이 생겨요. 핀마다 고칠 점을 적고 **수정 요청 보내기**, 또는 쓸 이미지를 체크하고 **최종 컨펌**.
5. 최종 컨펌하면 자동으로:
   - **용량 최적화**: JPG, 가로 1080px, sRGB, 품질 85
   - **내 Mac 저장**: `이미지정리/완성본 (contents controller)/계정/게시일_작업번호/` (컨펌된 캡션이 있으면 캡션 파일도 함께)
   - **Google Drive 복사**: Google Drive 데스크톱 앱 폴더의 같은 위치 (홈 > 완성본 저장에서 켜고 끄기)
6. 최종으로 고른 이미지가 가로 1080px보다 작으면, 최종 컨펌 때 고를 수 있어요: **Higgsfield 업스케일**(크레딧, Claude가 처리한 뒤 바로 저장) · **프로그램에서 확대**(무료) · **원본 유지**.

## 영상 제작 (4단계)

1. 영상 작업 화면에서 **스토리보드 맡기기** → Claude가 컷 구성(시간·장면·카메라·화면 문구)을 보내요.
2. 컷마다 **이미지 작업으로 시작**(이미지 → 영상)이나 **레퍼런스**를 붙일 수 있어요. 고칠 점이 있으면 수정 요청.
3. 승인할 때 편집 방식을 골라요. 중간에 바꿀 수 있어요.
   - **Claude가 편집**: Claude가 Higgsfield·CapCut 연결로 만들어서 보내요 (생성 전 예상 크레딧 확인).
   - **CapCut에서 내가 편집**: 자막 없이 내보낸 영상(mp4·mov)을 작업 화면에 올려요.
4. 재생하면서 고칠 지점에서 **메모 추가**(구간도 가능) → **수정 요청** 또는 **영상 컨펌**.
5. 영상 컨펌 때 만들 나라 버전(GLOBAL·JP·EU 중 판매하는 시장)을 고르면, Claude가 **모든 언어 자막을 한 번에** 써요 (줄마다 한국어 역번역).
6. 자막 컨펌 → **최종 컨펌**하면 프로그램이 나라별로 **자막을 영상에 입히고**(토큰 안 씀), H.264·가로 1080px로 최적화해서 저장해요.
   - 저장 위치: `완성본 (contents controller)/계정/게시일_작업번호/` — 나라별 영상, 자막 파일(SRT, 한국어 SRT), 자막 없는 원본(clean)
   - Google Drive에도 같은 구조로 복사돼요.

Claude에게 맡긴 일은 Claude 앱에서 **"contents controller 대기 작업 처리해줘"** 한 줄로 처리해요.

## 브랜드 기준

- **브랜드 전체**: 슬로건·포지셔닝, 계정별 톤, 금지 표현, 비주얼 기준
- **제품별(SKU)**: 시장별 제품명, 판매 시장, 핵심 성분·사용법·제품별 규칙, 기준 이미지, 등록 정보·전성분
- 고칠 때는 [수정] → 바뀐 내용 확인 → 이유 적고 저장. 저장할 때마다 버전이 오르고 **변경 이력**에 남아요. 언제든 이전 상태로 되돌릴 수 있어요.
- Claude가 기준을 바꾸자고 하면 **업데이트 제안**에 올라와요. 직접 [반영]해야 적용돼요.
- 처음 기준은 「DAMTIX B2B Product Introduction (Final v2) – 2026.10」 매뉴얼로 만들었어요.

## 이미지 폴더

바탕화면의 `이미지정리` 폴더를 지금 정리된 그대로 써요. 프로그램이 폴더 이름을 기억해요.

| 쓰임 | 폴더 |
|---|---|
| 제품 기준 이미지 | 01 다크스팟(DSS) · 02 PDRN(GTCP) · 03 NMN(GTCN) · 04 리페어(GTCR) · 05 리프팅(P7XL) · 06 아이크림(VLE) · 07 버블토너(HGB) · 08 아이크림 리필(VLER) |
| 그 밖의 이미지 | 00 누끼이미지 · 99 단체컷 · 실제 모델 · ai 모델 · 담틱스 로고 · 100 기타 이미지 |

- 제품 폴더 안의 하위 폴더(예: 패키지, 텍스처)는 그대로 묶어서 보여줘요.
- 폴더 이름을 바꿨다면 **브랜드 기준 > 제품별 > 기준 이미지**에서 다시 골라 주세요. 연결 상태는 홈 화면의 **이미지 폴더**에서 볼 수 있어요.
- Claude는 제품·모델 이미지를 만들 때 이 폴더의 사진을 참조해요.

## Claude가 쓰는 기능 (MCP)

| 기능 | 하는 일 |
|---|---|
| `get_brand_guide` | 브랜드 기준 읽기 (계정별 톤·금지 표현) |
| `list_products`, `get_product` | 제품 기준과 기준 이미지 경로 읽기 |
| `get_image_folders` | 이미지정리 폴더 지도 (누끼, 단체컷, 모델, 로고 폴더) |
| `check_text` | 문구 검사: 금지 표현, 판매하지 않는 시장, 일본 판매명 누락 |
| `propose_brand_update` | 기준 변경 제안 (승인해야 반영) |
| `get_change_history` | 변경 이력 보기 |
| `list_queue` | Claude가 할 일 목록 ("대기 작업 처리해줘") |
| `submit_caption` | 캡션·해시태그·멘션과 한국어 역번역 보내기 (기준 위반 시 거절) |
| `create_work`, `list_works`, `get_work` | 작업 기획하기, 일정·작업 보기 |
| `get_reference`, `submit_reference_analysis` | 레퍼런스를 직접 보고 분석 보내기 |
| `submit_drafts` | 구도 시안(SVG 스케치) 보내기 |
| `submit_images` | 만든 이미지 보내기 (주소 또는 Mac 파일 경로) |
| `view_work_image` | 시안·결과 이미지와 핀 메모를 직접 보기 |
| `submit_upscaled` | 최종 이미지 업스케일 결과 보내기 (받으면 바로 저장) |
| `submit_storyboard`, `submit_video` | 영상 컷 구성, 편집한 영상 보내기 |
| `submit_subtitles` | 나라별 자막을 한 번에 보내기 (프로그램이 영상에 입힘) |
| `view_video_frames` | 영상의 필요한 장면만 작은 사진으로 보기 (토큰 절약) |

## 데이터와 백업

- 모든 데이터는 프로그램 폴더 안의 `data/`에 저장돼요. 이 폴더만 백업하면 돼요.
- `data/`는 GitHub에 올라가지 않아요. 프로그램을 업데이트해도 데이터는 그대로예요.

## 업데이트

`update.command`를 더블클릭하면 최신 버전을 받고 프로그램을 다시 켜요. Claude 기능이 바뀐 업데이트라면 Claude 앱도 ⌘Q로 껐다가 다시 열어요.

## 개발자용

```bash
npm install
npm start        # 화면 서버 (http://localhost:4321)
npm run mcp      # Claude 연결 창구 (보통 Claude 앱이 직접 실행)
npm test         # 기준 규칙·작업 흐름 테스트
```

화면 디자인 기준은 [DESIGN.md](DESIGN.md)를 따라요.
